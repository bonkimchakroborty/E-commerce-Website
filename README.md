## 📌 Project Overview

GadgetBD is a professional and modern gadget eCommerce website designed for showcasing and selling tech products online.  
The project was converted from an agency/eCommerce-style design into a fully responsive frontend website using pure HTML, CSS, and Bootstrap.

The website focuses on clean UI design, responsive layouts, smooth user experience, and professional product presentation.
